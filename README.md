# Forno Augustus · Página do cliente

Página que o cliente abre pelo QR Code da plaquinha: marca o que pegou, informa o nome e paga no Pix (ou deixa anotado).
Os registros vão para o Firebase (projeto `forno-augustus-e7b66`) e aparecem no app da Talita e do Aluízio.

Endereço: https://albertjr99.github.io/forno-augustus/

- `index.html`, `client.js`, `app.css`: a página
- `config.js`: identificadores públicos do projeto Firebase
- `firebase.js`: SDK do Firebase empacotado
